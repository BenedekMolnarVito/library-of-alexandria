# The Evolving Software Stack: Blending Software 1.0, 2.0, and 3.0

**Authors**: Jared Hatfield
**Date**: 2026-04
**Type**: article

## Summary

Jared Hatfield gives one of the clearest explanations in this corpus for how traditional code, learned models, and language-directed agents fit together. The key idea is that the future is not a replacement story but a composition story: Software 1.0 still provides explicit logic, Software 2.0 still provides learned inference, and Software 3.0 puts natural language at the control layer.

The article is especially useful for separating "AI wrote this code" from "this is a new software paradigm." AI-generated code is still Software 1.0; the paradigm shift appears when language-driven systems orchestrate tools, models, and even other agents.

## Key Takeaways

- Software 3.0 is a control-plane shift, not a deletion of code
- Agents emerge when the LLM is choosing actions, not just generating text inside a fixed workflow
- Code, narrow models, and other agents all become capabilities once Software 3.0 is in control
- Letting agents write ad hoc code is a material step up in power, not a minor feature extension
- The architectural question becomes which layer is in the driver's seat

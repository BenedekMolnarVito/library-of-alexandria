# Paperclip AI: Open source platform focused on turning ai agents into a company

**Author**: Nikhil
**Published**: 2026-04-02
**Type**: Platform overview / deep dive

## Summary

Paperclip is an open-source orchestration platform for managing multiple AI agents as an organization. Not a chatbot framework, not a workflow builder—it's organizational governance for agents. Agents have jobs, budgets, roles, personas. Includes audit logs, task tracking, org charts, heartbeat scheduling. Solves the coordination problem: keeping agents from stepping on each other, tracking costs, maintaining context across sessions.

## Key Takeaways

- **Organizational structure** — CEO, engineers, QA, designers; each agent has a role, budget, skill set
- **Mission-driven context** — Every task traces up to company mission; agents understand why, not just what
- **Heartbeat system** — Agents wake on schedule, check inbox, act; persistent state across restarts (solves "Memento Man" problem)
- **Agent-agnostic** — Works with Claude Code, OpenClaw, Codex, Cursor, OpenCode, Gemini CLI
- **Self-hosted, MIT licensed** — No vendor lock-in; you pay only for LLM inference
- **Clipmart roadmap** — Pre-built company templates (content agencies, dev shops, trading desks); importable with one click
- **Governance built-in** — No agent can hire, spend, or execute major strategy without approval

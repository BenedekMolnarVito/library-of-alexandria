# Minimax M2.7: Self-Evolving Agent Model

**Authors**: Developers Digest
**Date**: 2026-03
**Type**: video-transcript

## Summary

This source frames MiniMax M2.7 as one of the first openly discussed models whose harness participated in its own evolution. The video combines benchmark and pricing commentary with a walkthrough of the lab's self-evolution loop: analyze failure trajectories, plan changes, modify scaffold code, run evaluations, and keep or revert changes over many rounds.

It also adds a practical deployment angle through MiniMax's token-plan pricing and Anthropic-compatible API surface, arguing that low-cost, agent-capable models matter because they make iterative real-world use much cheaper.

## Key Takeaways

- MiniMax is explicitly marketing self-evolution as part of the model story, not just benchmark numbers
- The important claim is not abstract autonomy but measurable harness improvement through iterative evaluation
- Agentic performance plus cost profile is the main reason the model matters
- Skills, MCP, and harness design are treated as core performance levers
- Cheap request plans change what kinds of experimentation are economically reasonable

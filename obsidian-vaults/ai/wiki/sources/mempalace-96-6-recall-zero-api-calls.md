# MemPalace: 96.6% Recall with Zero API Calls

**Authors**: Mandar Karhade  
**Date**: 2026-04  
**Type**: article

## Summary

This source argues for a "raw text first" memory thesis: preserve full conversational signal and rely on retrieval plus optional reranking, rather than early summarization. It also details hybrid retrieval stages and cost claims for local-first memory operations.

## Key Takeaways

- Raw verbatim storage is framed as the core driver of strong recall performance.
- Spatial organization (wings/rooms/drawers) is presented as a navigation and retrieval-precision aid.
- Hybrid retrieval adds keyword overlap, temporal boosts, and preference extraction before optional LLM reranking.
- The source is bullish on local-first economics, while acknowledging claim scrutiny.

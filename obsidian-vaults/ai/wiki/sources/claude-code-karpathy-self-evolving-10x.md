# Claude Code + Karpathy's NEW Self-Evolving System = 10x Code Generation

**Author**: WorldofAI
**Published**: 2026-04-06
**Type**: Video transcript + tutorial

## Summary

Demonstrates how Andrej Karpathy's LLM Wiki (self-evolving knowledge system) amplifies Claude Code's capabilities. Instead of isolated prompts, agents can reference structured, auto-maintained wikis. Three-layer system: raw sources (immutable), wiki (LLM-generated markdown with links), and schema (rules for maintenance). Includes step-by-step setup using Obsidian and Claude Code.

## Key Takeaways

- **Three-layer architecture**: Raw sources, Wiki (markdown), Schema (rules)
- **Humans explore; LLMs maintain** — Keeps knowledge interconnected and consistent without manual bookkeeping
- **Self-improving loop** — Lint runs detect gaps, contradictions, missing links; LLM auto-fixes
- **Agent reasoning improved** — Agents can drill into structured wiki pages instead of single mega-prompts
- **Setup is fast** — 5-minute Obsidian vault + Claude Code integration
- **Practical example**: Design library (screenshots, CSS, Figma links) lets agents generate on-brand frontends

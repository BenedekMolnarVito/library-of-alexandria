# Paperclip

Paperclip is an AI automation platform built on top of [[wiki/entities/claude-code]] that extends it with governance, team collaboration, and enterprise-grade controls — positioning itself above Claude Code in the abstraction stack rather than as a replacement or alternative.

## Background / History

Paperclip was created by Jack Roberts as a commercial layer on the Claude Code ecosystem. Where Claude Code is a developer tool for individual use, Paperclip addresses the organizational challenges that arise when teams of developers use AI coding assistants — auditability, access controls, shared context management, and governance over what AI agents are allowed to do. The name is either a reference to the AI alignment thought experiment (the Paperclip Maximizer) or simply a branding choice, but the governance angle makes the alignment connection plausible.

## Key Contributions / Features

**Enterprise Governance Layer**: Paperclip adds organizational controls over Claude Code usage — who can run agents, what actions agents are permitted to take, logging of agent actions for audit purposes, and team-level shared configurations. These features address the "dark code" problem ([[wiki/entities/nate-b-jones]]) at the organizational level, providing visibility into what AI agents are actually doing in production codebases.

**Team Collaboration**: Paperclip enables shared skills, shared CLAUDE.md configurations, and team-level agent workflows — allowing organizations to standardize their AI coding practices rather than having each developer manage their own idiosyncratic setup.

**Comparison vs. Claude Code and OpenClaw**: [[wiki/entities/nate-herk]] compared Paperclip head-to-head with Claude Code and [[wiki/entities/openclaw]], providing practitioners with a three-way evaluation of the agentic coding tool landscape. (Source: [[wiki/sources/claude-code-paperclip-destroyed-openclaw]])

**AI Governance Platform**: Paperclip explicitly positions as an AI governance product — not just a productivity tool but a system for managing AI risk in software development contexts. This framing anticipates enterprise requirements that are beginning to emerge as organizations scale AI coding tool adoption. (Source: [[wiki/sources/paperclip-ai-governance-platform]])

## Role in AI Landscape

Paperclip represents a natural evolution of the agentic coding ecosystem: as individual tools mature, the next problem layer becomes organizational management and governance. If Claude Code is the "IDE for AI programmers," Paperclip is aiming to be the "project management and governance layer for AI programming teams." Whether this layer becomes a distinct product category or gets absorbed into the core tools (Anthropic adding governance features to Claude Code) is an open question, but Paperclip is early evidence of the organizational AI governance market forming.

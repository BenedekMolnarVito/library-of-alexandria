# OpenAI

OpenAI is the creator of the GPT model family, ChatGPT, and Codex CLI — one of the two dominant players in the agentic coding tool market alongside [[wiki/entities/anthropic]]. Founded with an explicit safety and openness mission, OpenAI has evolved into a primarily commercial enterprise competing at the frontier of AI capability.

## Background / History

OpenAI was founded in 2015 as a non-profit AI safety organization by a group including Sam Altman, Greg Brockman, [[wiki/entities/andrej-karpathy]], Elon Musk, Ilya Sutskever, and others. It converted to a "capped-profit" structure in 2019 to attract capital, and has since raised billions in investment from Microsoft (which has deeply integrated OpenAI models into its cloud and productivity products). Several prominent departures — including Karpathy, Sutskever, and the founders of [[wiki/entities/anthropic]] — have shaped the competitive landscape by creating well-funded competitors with different organizational cultures and safety philosophies.

OpenAI's release of GPT-3 in 2020 and GPT-4 in 2023 established it as the frontier capability leader, though Anthropic's Claude models have competed closely on coding and instruction-following tasks. The release of ChatGPT in late 2022 made OpenAI a household name and accelerated the consumer AI adoption curve by several years.

## Key Contributions / Features

**GPT Model Family**: OpenAI's GPT series — from GPT-3 through GPT-4 and GPT-5.4 — established the standard for large language model capability. The models power ChatGPT, the API used by thousands of developers, and form the backbone of Microsoft Copilot.

**Codex CLI**: OpenAI's terminal-based coding agent, analogous to Claude Code but running on GPT models. Codex CLI was compared side-by-side with Claude Code by practitioners, with results varying by task type. Like Claude Code, it operates as an autonomous agent capable of file operations, command execution, and multi-step programming tasks. (Source: [[wiki/sources/codex-and-claude-side-by-side]])

**ChatGPT**: The consumer product that introduced conversational AI to the mainstream, achieving 100 million users in record time and establishing the chat interface as the default human-AI interaction paradigm.

**Memory and Context Portability Competition**: OpenAI is competing directly with Anthropic on memory systems — how agents maintain state across conversations, what users can control about persistent memory, and how context can be shared across tools and agents. This competition reflects the growing importance of persistent agent state as a product moat. (Source: [[wiki/sources/anthropic-openai-memory-context-portability]])

## Role in AI Landscape

OpenAI remains the most visible and commercially dominant AI company, setting the pace of competition that other labs — including Anthropic — must respond to. In the agentic coding space specifically, OpenAI's Codex CLI competes directly with Claude Code, and the side-by-side comparisons conducted by practitioners provide real-world performance data beyond what either company publishes. OpenAI's API standards (including the OpenAI-compatible API format used by many open models) have become an unofficial industry standard, enabling [[wiki/entities/zhipuai]], [[wiki/entities/google-deepmind]], and others to distribute their models through compatible interfaces.

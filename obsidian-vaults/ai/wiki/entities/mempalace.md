# MemPalace

MemPalace is an open-source, local-first AI memory system that stores and retrieves long-horizon context for agent workflows. It is positioned as an alternative to summary-first, cloud-centric memory stacks by combining full-history retention, structured organization, and lightweight wake-up context.

## Key Characteristics

- Spatial organization (wings, rooms, halls, drawers/closets) for scoped retrieval.
- Local operation with low infrastructure overhead and strong data-control posture.
- Tool-oriented integration via MCP for direct assistant access.
- Ongoing debate around benchmark interpretation and AAAK compression fidelity.

## Role in AI Landscape

MemPalace represents a high-visibility push toward user-owned memory substrates for agents. Whether or not all headline claims hold, it has accelerated discourse around local-first memory economics, memory architecture ergonomics, and benchmark rigor in AI memory products.

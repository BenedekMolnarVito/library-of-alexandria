# Tribe Product Questions

- "Offline Impact Is the Metric" --> how do we measure this?
- "We take responsibility for the social, emotional, and cultural impact" -->how?
- Első kritika ami érhet minket: az oké, hogy összehozzuk a like-minded embereket, de arra is (néha) szükség van, hogy pont ellentétes nézőpontú emberekkel kontaktoljunk (különben nincs fejlődés).
- the "activation moment." --> automatikusan menne a háttérben és szólna, ha talált egy jó ötletet/embert? Ha igen, honnan jönne az input az éppen aktuális viselkedéséről.
- This makes Tribe habit-forming without being addictive. --> how do we know it wont be addictive?
- "We have real human outcome data:" --> how do we get it?
- "They need partners often and repeatedly" --> hogyan gyűjtünk róluk adatokat, ha első találkozás után számot cserélnek?
- "Good intentions → momentum and impact" --> What if somebody has bad intentions? How do we account for that? Do we take responsibility for "bad people"?

## 2026.02.14.

- @Product development/Product Experience: "Tom is in the same emotional state and wants to talk about similar topics." <-- if it is a notification (no prompt entered), then how do we know the user's current mood?
- @Product development/UI Blueprint: "**"We found your people."** → Shows 1–3 ideal matches" <- elég ennyi? Mit mutatunk meg? Egy rövid, akár AI-generált írás a matchről? Az emberek azért szeretnék nagyjából tudni, hogy kivel fognak találkozni...
- @User Story: "fallback top 3 closest matches if no perfect match exists." <- what is a perfect match?
- What if somebody wants to plan ahead? e.g. "I want to start going to the gym from next month"... <- when finding matches, we need to look at the relevant time window!
- @PRD/Acceptance criteria: "Matched person receives contextual message with I'm interested / Not today" <- email for MVP, and push notification later?

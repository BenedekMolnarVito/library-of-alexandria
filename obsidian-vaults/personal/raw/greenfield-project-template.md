## Overview

A reusable template prompt for initializing greenfield software projects with an agentic coding workflow. Uses a **Habit Tracker** app as an example to demonstrate how to fill in each section.

## Template Structure (known sections)

- **Project Overview** — high-level description, goals, non-goals
- **Tech Stack** — backend, frontend, database, deployment choices
- **Key Features** — minimum viable feature list
- **Architecture** — component diagram, data flow, API design
- **Planning Instructions** — how Planner agent should break down work for Worker agents
- **Testing Requirements** — unit, integration, and UI behavior test expectations
- **Environment Variables** — required secrets/config with instructions on how to obtain them
- **Common Sense Checks** — knowledge gaps and ambiguities for the agent to resolve before coding

# Personal Vault Initialization Prompt

**Authors**: Molnár Benedek
**Date**: 2026-04-19
**Type**: prompt / specification

## Summary

The founding document of the Personal Vault. Contains structured personal information, professional details, interests, preferences, hardware inventory, and hobby server configuration. Also instructs the agent to scrape OneDrive for additional context.

## Key Takeaways

- The vault is designed to be referenced by other LLM agents — structure and accessibility are first-class concerns
- Information is not static and should be updated over time
- Bilingual support (English/Hungarian) is required
- SSH credentials for the hobby server should be asked at runtime, not stored
- The Personal Vault should mirror the `ai` vault's structure for consistency

# Personal Vault Overview

This vault is the personal knowledge hub of **Molnár Benedek** — a Budapest-based software engineer, former neuroscientist, and self-described generalist who loves connecting dots between fields. It is designed to be the single source of truth about his life, career, preferences, and personal infrastructure, accessible both by the user and by any LLM agent that needs context about him.

## Who Is This Person?

- **Biology BSc & MSc** → **Neuroscience PhD program** → **Scientific Translator** → **Business Informatics BSc** → **Medical IT** → **Back-end Developer** → **MLOps / Data Scientist**

This trajectory means he thinks in systems (biological, computational, and business), writes in two languages (Hungarian and English), and approaches problems from multiple angles. The ADHD self-diagnosis drives a preference for flexible tools that adapt rather than constrain.

## Design Philosophy

This vault is built with three core principles:

1. **Agent-accessible**: Structured so any LLM agent can quickly find and use personal context — preferences, credentials (non-sensitive), infrastructure details, career history
2. **Bilingual**: Documents exist in both Hungarian and English; the vault processes and organizes both
3. **Living document**: Information is not static. As life changes, the vault evolves. New sources can be ingested, pages updated, and the structure adapted

## Scope Notes

This vault covers:
- Personal identity, preferences, and habits
- Professional career history and skills
- Financial records and investment activity
- Infrastructure and hardware inventory
- Interests, hobbies, and creative projects
- Key documents and certificates (via OneDrive inventory)

It does **not** store:
- Sensitive credentials (SSH passwords, API keys)
- Medical records content (only references)
- Full financial data (only structure and categories)

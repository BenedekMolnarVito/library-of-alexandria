# Software Engineering

The primary professional domain of [[wiki/entities/molnar-benedek]]. A career that was catalyzed by the intersection of neuroscience research and programming, evolving from data analysis scripts into full-stack back-end development.

## Technology Stack

### Primary Languages & Frameworks

| Technology | Experience Level | Context |
|-----------|-----------------|---------|
| **Python** | Advanced | web2py, Django, ML/DL, web scraping, ETL, LLM APIs |
| **C# / .NET** | Advanced | ASP.NET Core, Blazor, Entity Framework Core, MVC/MVVM |
| **SQL** | Advanced | MSSQL, DB2 (triggers, stored procedures) |
| **R** | Intermediate | Statistics & analysis for research |
| **MATLAB** | Intermediate | Electrophysiology analysis |

### Tools & Platforms

- **Cloud**: Microsoft Azure (App Service, Functions, Event Bus, Key Vault)
- **Visualization**: Power BI, Tableau
- **IDE**: Visual Studio Code + GitHub Copilot
- **Version Control**: Git/GitHub
- **Containers**: Docker (used extensively on [[wiki/entities/hobby-server]])
- **Architecture**: Domain-Driven Design (DDD)
- **Methodology**: Scrum

### AI/ML Stack

- OpenAI APIs, llama-index
- ML: kmodes, fuzzy string matching, basic NLP
- ETL: pandas, numpy, beautifulsoup, selenium
- MLOps on Azure

## Career Trajectory

1. **Neuroscience researcher** → MATLAB/R scripts for data analysis
2. **Medical Science Liaison** → Python web scraping, first programming exposure
3. **Medical IT Associate** → Blazor dashboards, ML scripts, ETL pipelines
4. **Back-end Developer** → Full .NET Core and Python web development
5. **MLOps / Data Scientist** → Azure cloud, AI services, LLM integration

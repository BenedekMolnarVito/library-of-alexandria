# Self-Hosting

The practice of running your own server infrastructure for personal projects and services. A significant hobby and learning domain for [[wiki/entities/molnar-benedek]].

## Current Setup

See [[wiki/entities/hobby-server]] for full details. Key components:
- **DuckDNS** dynamic DNS pointing to `vitoscaletta.duckdns.org`
- **nginx** reverse proxy for routing traffic to services
- **Docker** containers for running applications
- **4TB NAS** for file storage, media, and backups
- **Old HP laptop** as the hardware platform

## Skills Developed

- Linux server administration
- Docker containerization and orchestration
- Reverse proxy configuration (nginx)
- DNS management (DuckDNS)
- Network storage (NAS mounting)
- SSH remote access
- Web application deployment

## Motivation

Used for:
1. Hosting personal web applications
2. Testing and experimentation
3. Learning server management and networking
4. File and media storage/backup
